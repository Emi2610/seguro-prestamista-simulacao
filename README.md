# Seguro Prestamista — Protótipo V2

Protótipo interativo para apresentação de case de gestão de produto.

## O que há nesta versão
- Jornada de cliente em 7 etapas.
- Simulação de valor e prazo com JavaScript.
- Oferta contextual de proteção.
- Caminho com contratação e sem contratação.
- Área de acompanhamento da proteção.
- Botão para alternar entre **Modo cliente** e **Modo gestor**.
- Dashboard com funil ilustrativo.
- Teste A/B de linguagem.
- Hipóteses de experimentos.
- North Star e métricas de qualidade.
- Alerta sobre validação regulatória.

## Como usar
Abra `index.html` no navegador. Não precisa instalar nada.

## Estrutura
- `index.html`: estrutura das telas.
- `css/style.css`: visual.
- `js/app.js`: navegação, sliders e simulações.
- `README.md`: instruções.

## Observação
Todos os números do dashboard e os valores financeiros são **ilustrativos**. O projeto não é um aplicativo oficial do Itaú nem uma oferta de seguro.
